# OsteoTracker
Smart IoT-Based Early Detection and Monitoring System for Osteoarthritis  This project aims to develop a low-cost, portable, and IoT-enabled prototype for the early detection and monitoring of osteoarthritis (OA).

The system uses an ESP32 microcontroller integrated with an AD5933 impedance measurement module to collect bioelectrical impedance-related measurements from the target joint area.

The collected measurements are processed by the ESP32 and transmitted through the internet to Firebase, where the data can be stored and monitored. A mobile-friendly interface can then display the patient's measurements and provide alerts or notifications when the recorded parameters show patterns that may require further clinical evaluation.

The proposed system is intended as a screening and monitoring prototype, not a replacement for professional medical diagnosis. By combining impedance sensing, embedded systems, cloud connectivity, and mobile monitoring, the project aims to explore a convenient and affordable approach for supporting the early identification of possible OA-related changes.
